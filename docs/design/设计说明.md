# 证据台界面设计

参考图由内置 Image Gen 生成，用于统一第一版页面样式；本次为直接实施模式，未单独要求用户审批视觉图。参考图片为 `workspace-concept.png`，尺寸 1536 × 1024。

## 设计约定

| 项目 | 取值 |
| --- | --- |
| 背景 | 冷灰 `#f5f7fb` |
| 内容面 | 白色 `#ffffff` |
| 主文字 | 深蓝黑 `#182238` |
| 次文字 | 灰蓝 `#718096` |
| 主色 | 蓝色 `#3158d5` |
| 边框 | `#e5e9f0` |
| 圆角 | 8px |
| 字体 | Microsoft YaHei、PingFang SC、系统无衬线字体 |
| 桌面侧栏 | 约 240px |
| 主区左右留白 | 约 40px |

主屏包含纯文字品牌与导航、四列统计、单个横向项目记录、最近贡献表格、四步验收流程。色彩用于区分操作和状态，无装饰性图表或照片。其他业务页沿用相同的表格、表单、按钮和对话框样式。

## 首屏文案基线

品牌“证据台”，说明“学生团队项目”。导航依次为“项目总览”“任务与标准”“贡献申报”“验收工作台”“个人报告”。标题“让每一份贡献有据可查”，说明“连接任务、个人工作与验收依据。”，教师主操作“创建项目”。

统计标签为“进行中的项目”“项目任务”“待验收申报”“已确认贡献”。演示初始值为 1、3、1、1，实际界面由 API 计算。项目列表中展示“校园二手交易平台”。下方包含“最近贡献”和“验收流程”。

学生身份隐藏教师操作；个人报告与近期申报只展示当前身份有权查看的数据。创建真实项目、提交和验收后统计及行数随之变化。日期使用运行当天日期。手机布局按可读性重排侧栏和主区，功能保持一致。
